# SEi_SNEAELIS

**SEI dashboard** tailored to the **SNEAELIS** team's workflow.

## 🔁 What it does

- `sei_sneaelis_dashboard.py` — Playwright-driven dashboard/scraper that collects SEI process data for the team's routine (see script header for input/setup).

## ▶️ Run

```bash
python sei_sneaelis_dashboard.py
```

> Requires Chrome connectivity (CDP debug port) as used by the other SEI modules..

## 📦 Dependencies

`playwright` · `pandas` · `openpyxl` · `colorama`
