# Tel+E_mail_DPF

Collects **phone + e-mail** contact information from DPF workflows (processes associated with the DPF area).

## 🔁 What it does

- `Tel+E_mail_DPF.py` — Playwright automation that looks up contact data for a list of processes/entities and writes them to an output spreadsheet.

## ▶️ Run

```bash
python Tel+E_mail_DPF.py
```

> Input list format and Chrome setup: see script header..

## 📦 Dependencies

`playwright` · `pandas` · `openpyxl` · `colorama`
